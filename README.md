# Фишинг: Найди подделку
**Информация об авторе:** _впиши название команды/своё имя_, Кибербезопасность, группа _впиши номер группы_
**Команда проекта:** _впиши ФИО участников через запятую_
**Краткое описание:**
Обучающая веб-игра в жанре point-and-click по кибербезопасности. Проект реализован на чистом HTML, CSS и JavaScript (без бэкенда). Игрок выступает в роли сотрудника вымышленной компании NordTech и за 8 раундов учится распознавать фишинговые письма, поддельные сайты и мошеннические сообщения в мессенджерах: кликает по подозрительным деталям (адрес отправителя, домен сайта, вложения, ссылки), получает пояснения и решает — перед ним подделка или настоящее сообщение. За верные и неверные решения начисляются очки, отображается индикатор «Бдительность», а по итогам игры выдаётся уровень цифровой грамотности и список правил распознавания фишинга.

## 📋 Требования
* Любой современный браузер (Chrome, Firefox, Edge, Safari)
* Node.js 14+ и npm (для удобного локального запуска)

## 🚀 Как запустить
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/username/repo.git
   cd repo
2. Установите зависимости (локальный веб-сервер):
   ```bash
   npm install
3. Запустите проект:
   ```bash
   npm start
(Альтернативный способ без Node.js: просто откройте файл Фишинг_Найди_подделку.html двойным кликом в любом браузере).
